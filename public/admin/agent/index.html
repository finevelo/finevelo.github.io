Agent

Der Agent läuft auf GitHub Actions nach dem Zeitplan aus Agent: Zeitplan & Regeln. Hier hinterlegst du den Claude-API-Schlüssel und startest ihn von Hand.

1. Mit GitHub verbinden

Fine-grained Token nur für das Repo finevelo/finevelo.github.io mit den Rechten Contents, Secrets und Actions (Read and write). Bleibt nur in diesem Browser-Tab.

2. Claude-API-Schlüssel

Prüfe …

Der Schlüssel wird hier im Browser verschlüsselt und direkt als geschütztes GitHub-Secret ANTHROPIC_API_KEY gespeichert. Er landet nicht im Repo und ist danach für niemanden mehr lesbar, nur ersetzbar.

3. Läufe

„Jetzt ausführen“ ignoriert den Zeitplan. Ergebnisse erscheinen als Entwürfe in der Redaktion.
